# 🛡️ CloudSentinel AI

AI-powered cloud cybersecurity monitoring and threat detection platform.

## 📌 Overview

CloudSentinel AI is a cybersecurity platform designed to help monitor
cloud resources, detect security threats, scan vulnerabilities, track
compliance, and provide AI-powered cybersecurity assistance.

## ✨ Features

- 🔐 User Authentication
- ☁️ Cloud Resource Monitoring
- 🛡️ Security Scanner
- 🚨 Threat Feed
- 📋 Compliance Monitoring
- 📊 Security Reports
- 🤖 AI Copilot
- 👤 User Profile
- ⚙️ Settings
- 📡 Real-time Security Monitoring

## 🛠️ Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Recharts

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
